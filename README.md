# UAV Scenario Design using MATLAB

## Overview

This project presents a UAV simulation scenario developed using
MATLAB UAV Scenario Designer. A quadrotor UAV was configured to
operate in an environment containing polygon-based obstacles/buildings,
with a LiDAR sensor and predefined waypoints and trajectory.

## Objectives

- Create and configure a quadrotor UAV scenario
- Design an environment containing obstacles/buildings
- Configure a LiDAR sensor for the UAV
- Define UAV waypoints and trajectory
- Prepare the scenario for UAV animation and simulation

## Software & Tools

- MATLAB
- UAV Toolbox
- UAV Scenario Designer

## Scenario Components

### Quadrotor UAV
A quadrotor was added to the UAV Scenario Designer canvas and its
relevant parameters were configured.

### Environment

Three polygon-based objects were created and configured to represent
obstacles/buildings in the UAV environment.

### LiDAR Sensor

A LiDAR sensor was added to the quadrotor and its required parameters
were configured for sensing the surrounding environment.

### Waypoints and Trajectory

Waypoints were defined for the quadrotor, followed by the definition
of its trajectory through the scenario.

## Result

The complete scenario was configured and prepared for animation,
including the quadrotor, environment, LiDAR sensor, waypoints,
and trajectory.
